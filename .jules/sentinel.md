## 2024-04-27 - [Command Injection Prevention in A2ASidecarManager]
**Vulnerability:** A command injection vulnerability was discovered in `A2ASidecarManager._restart_sidecar` within the local Python proxy manager. User-provided `credential_path` (and configuration options from environment variables like `compose_dir`, `compose_project`, `compose_service`) were directly concatenated into a shell command formatted string. The string was executed via `asyncio.create_subprocess_shell`, exposing the application to arbitrary shell command execution if paths were maliciously crafted or manipulated.
**Learning:** Shell strings constructed from inputs should always be properly escaped before being executed. Using `asyncio.create_subprocess_shell` with direct string injection instead of `asyncio.create_subprocess_exec` passing arguments as a list relies entirely on the developer explicitly safely quoting the command.
**Prevention:** Always use `shlex.quote()` when concatenating user-controlled variables into a shell command, or use the `asyncio.create_subprocess_exec()` mechanism which safely passes uninterpreted arguments directly to the process. Since the existing command used shell features (`&&`), applying `shlex.quote` directly to the parameters before inclusion in the format string effectively prevents shell injection while allowing the shell structure to execute correctly.
